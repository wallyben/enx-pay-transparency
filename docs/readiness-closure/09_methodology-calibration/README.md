# R10 — Methodology Calibration (Readiness-Closure)

This folder contains the **governance artifacts** for **Methodology v1 calibration evidence packaging** during **Wave R — Readiness-Closure**.

## What lives here

- `METHODOLOGY_CALIBRATION_EVIDENCE_v1.md`: governance requirements for calibration evidence (inputs, outputs, evidence references, challenge handling, and sign-off expectations), explicitly **version-bound** and **perimeter-bound**.
- `METHODOLOGY_CALIBRATION_PACK_TEMPLATE_v1.md`: the required, repeatable template to package a calibration evidence bundle without hiding disagreements or implying approvals.

## Governance-only (binding)

These artifacts define **methodology calibration evidence governance only**.

They are produced in **MOCK/TEST readiness-closure mode** and do **not** constitute:
- real calibration execution or real calibration results,
- methodology approval/sign-off,
- pilot authorization, pilot entry, or pilot execution.

Pilot entry remains prohibited until **R17** passes and a new GO decision is recorded under the governing authority model.
